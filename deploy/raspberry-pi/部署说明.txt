二、部署（三步）
------------------------------------------------------------------------
① 放到树上并解压

   mkdir -p /vol1/1000/harness && cd /vol1/1000/harness
   tar -xzf valimart-harness-gateway-arm64.tar.gz     # 解出 valimart-gateway/

② ★ 先解决基础镜像（国内直连 Docker Hub 不通，这步不做会一直卡住）★

   sudo docker pull docker.m.daocloud.io/library/node:25-slim
   sudo docker tag docker.m.daocloud.io/library/node:25-slim node:25-slim

   或者在飞牛面板里配好「镜像加速」再往下走。

③ 一键脚本

   cd /vol1/1000/harness/valimart-gateway/deploy
   chmod +x deploy.sh
   ./deploy.sh 10.56.41.60                            # 数据目录默认用 <应用目录>/data
   # 指定数据目录（推荐放 SSD 卷）：
   ./deploy.sh 10.56.41.60 /vol1/1000/harness/data

   脚本会：写 server/config.local.json（publicUrl 换成你给的地址）→ 写 deploy/.env
   （APP_DIR + GATEWAY_DATA）→ 建数据目录 → 自动决定是否用 sudo → docker compose
   up -d --build → 等健康检查 → 打印下一步。

   手动做也可以，见 deploy/README.md。

四、必须知道的坑（都是实测踩到的）
------------------------------------------------------------------------
1. docker 需要 sudo。飞牛上普通用户不在 docker 组，deploy.sh 会自动加 sudo；
   手动执行请用 sudo docker compose ...。
2. 基础镜像拉不动 docker.io。见上面第②步；Dockerfile 也支持
   --build-arg NODE_IMAGE=docker.m.daocloud.io/library/node:25-slim。
3. APP_DIR 必须显式写绝对路径（.env 里）。用 ../.. 这类相对路径会在
   「散文件」和「tar 解包」两种布局下挂错一级，容器报
   Cannot find module '/app/server/src/index.js'。
4. server/config.local.json 必须在 up 之前是「文件」，否则 Docker 会建同名目录，服务起不来。
5. 数据目录放 SSD/NVMe，别放 SD 卡；容器删了数据不丢的前提是挂了 /data 卷。
6. Docker bridge 下局域网自动发现（UDP 18790 组播）基本失效，客户端手填 IP 即可；
   本包配置已 lanDiscover: false。
7. 别在树莓派上点管理页的「内核试打补丁 / 发布」——要 npm 装原生依赖，ARM64 未验证且很慢。
   内核构建继续在 x64 机器上做，再从那边发布到这台网关。
8. 员工客户端只有 Windows 版；树莓派上只跑服务端。


五、日常操作
------------------------------------------------------------------------
cd /vol1/1000/harness/valimart-gateway/deploy
sudo docker compose logs -f --tail 100    # 日志
sudo docker compose restart               # 改完 config.local.json 后重启
sudo docker compose down                  # 停止（数据在 /data，不丢）
sudo docker compose up -d                 # 起

备份：
sudo docker exec valimart-gateway node scripts/backup-gateway.mjs --data-dir /data --out /data/backups/latest.zip

升级：解压新包覆盖 valimart-gateway/（数据目录在包外，不受影响），再 up -d --build。
