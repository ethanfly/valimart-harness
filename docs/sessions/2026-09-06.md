## 本轮修掉的（按域）

### 体验 / desk-ui（client/src）
- **跨任务编辑残留（最严重）**：任务卡正文输入在任务之间串数据。任务详情加 `key={task.id}` 重挂载；正文失焦即静默保存；点「保存 / 采用」按钮 mousedown 置 skip 防止旧草稿覆盖刚采用的内容。
- 验收四格状态画错：退回的 02/03 不再显示成已通过（显示 初审驳回/终审驳回+时间），未走到的阶段不再误标完成。
- 快速推理：Ctrl+Enter 连击会双提交 → busyRef 同帧守卫；选模型失败时下拉回滚；useFetch 过期响应丢弃（防乱序覆盖）。
- 附件插入：文件名含引号/控制字符无法变成 @mention 时，只上传不引用——toast 明说「已上传但未插入引用」并统计跳过数；计入插入数不再误报。
- 网关请求 20s 超时（大附件 120s），超时提示区分于普通错误；轮询防重入。
- 人员名单为空时自动重试（不重启客户端）。
- 侧栏：任务 tab 在窄栏里不再死胡同（点「任务」自动展开侧栏）；首载不闪「暂无任务」。

### 桌面壳 / 脚本
- 内核运行中崩溃：弹「运行中断」对话框（文案/按钮与启动期区分），并 killTree bootstrap 子进程防孤儿。
- `close-prompt.html`：键盘焦点在「退出/取消」时 Enter 不再先触发「后台运行」（键盘用户终于能退出）。
- `launch.mjs`：die() 不再把已 spawn 的网关/客户端留成孤儿（先 killTree 再退）；三个 spawn 补 error 监听。
- `main.js` runBootstrap 加 180s 总超时（解压卡死不再永远停在 splash）；删死代码 waitHttp。
- 日志目录 / Electron userData 建不出来时降级不裸崩。
- `build-payload.mjs`：`--out` 任意路径不再整目录 rmSync（只清直接子项，疑似项目根直接拒绝）；`argOf` 全家桶（5 处脚本）不把 `--xxx` 当参数值吞掉。
- `kernel/update.mjs`：临时内核前缀（几百 MB）prepare 完即清，不再每次泄漏一份到 %TEMP%。
- `backup-gateway.mjs`：isMain 双侧 realpath。
- bootstrap linkJunction：删除失败（EPERM/EBUSY）不再被当 ENOENT 吞掉。

### 网关服务端（server/src）
- **断连不取消上游（实证）**：llm-proxy 原来 `req.on('close')` 在请求体读完就触发、监听永远错过；改为响应侧探测（res close 且未写完 → abort 上游）。用户点停止/关页面后不再把整段生成跑完、不再按全量记账。
- 请求体 `null`（合法 JSON）不再 500，给 400。
- **额度 TOCTOU**：同一用户同一上游的请求串行（`(userId:provider)` 门闩），exceeded() 与 record() 之间不再能并发双超。
- **store 半提交**：JsonFile / SqliteFile 的 update() 加快照回滚——mutator 抛错时内存不再残留改动、被下一次保存落库；`addDeliverables` 改三段式（先校验 → 全部写盘 → 成功才改内存并留痕，中途失败回滚已写文件）；`removeDeliverable` 先删盘后改内存。
- **网关令牌不永久有效**：签发带 TTL（=登录会话 TTL），findGatewayToken 拒绝过期令牌、并校验绑定会话未被吊销——重登录不再无限累积永久令牌。
- 人员周额度 NaN/Infinity 校验（原来设错一个数 = 该员工永久免限额）。
- 公司盘 DELETE 禁止目录整删（rmSync recursive 会把整棵 inbox / _office 连交付物删掉）。

### desk-host（plugins/desk-host）
- **镜像删除不收敛**：个人区文件在网关被删后，本机旧副本下一轮又 PUT 回去“复活”。拉取时给远端删除记墓碑（隐藏文件持久化），回推跳过墓碑；远端重现自动取消。
- `abs()` 越界检查补 path.sep（防根目录同名兄弟目录穿透）。
- mirror.sync() 整体互斥（心跳 / 手动 / attach 并发不再双写同批判定）。
- `/desk/api` 加来源校验（Sec-Fetch-Site / Origin）——本机接口只服务工作台页面，盲 CSRF（网页偷调 attach-local 上传本机文件、/open 拉资源管理器、/gw 改数据）被挡；readJson 拒绝非 JSON content-type、坏 JSON 给 400。
- 重登输错密码不再连坐清掉仍有效的登录会话与模型路由（fail 对 login/setup 的 401 豁免）。
- writeAttachments 先算总大小再落盘（超 64MB 不再留半截附件）。
- 内核更新：pending 记录在但 tar 已丢（清盘/杀软）不再永远短路成“已下载”；bootstrap 侧同步清 stale pending。
- gateway-client 超时覆盖 body 读取阶段（大 tar / 附件中途断流不再挂到内核超时）。
