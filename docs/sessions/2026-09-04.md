## 做了什么

### 服务端 `server/`（Node，无第三方依赖）

- 公司账号登录、登录会话、按登录设备绑定的网关令牌（签发 / 重签 / 登出收本机 / 管理员吊销收全部）
- `/v1/*` 模型代理：上游密钥只在服务端；按人记账（`usage.jsonl`）、每人每周额度（按角色）、满额 429
- 模型通道目录 `channels.js`：管理员在客户端接入 Grok / ChatGPT / Claude 订阅或 OpenAI / Anthropic / DeepSeek key，
  凭据落 `server/data/channels.json`，全员模型目录即时更新（心跳携带 `modelsSignature`）
- 公司盘 `drive.js`：`_shared/`（手册 + 六层共享经验）、`_office/<账号>/`（个人记忆）、`projects/inbox/<任务>/`；
  按人隔离，员工只能追加日志层
- 任务 `tasks.js`：四格验收 `draft → pending_review → pending_final → approved / rejected`、审核人、交付物、工作日志、关联进程
- 知识检索 `knowledge.js`：`/api/knowledge/search` —— 「公司里有没有人做过」→ 谁 / 何时 / 在哪
- 管理页 `/admin`（`admin-page.js`）：状态、公司盘三区、模型通道、知识库查询；登录不签网关令牌
- 测试 `test/gateway.test.js`：12 个端到端用例

### 客户端插件 `plugins/`

- `desk-host`（dsh 宿主）：登录 / 心跳 / 令牌失效即 `needsRelogin`、模型路由按厂商分组写进 `dsh-llm-pi-ai`、

## 踩过的坑与修法

| 现象 | 原因 | 修法 |
|---|---|---|
| 网关重启后发消息报 `API key is invalid` | 令牌策略是「一人一枚」：管理页 / 第二台电脑一登录就把旧令牌作废，而心跳查的是「这个人有没有任意有效令牌」，查不出来 | 令牌绑定登录会话；管理页登录 `gatewayToken: false`；心跳查「本机这枚」；失效即弹登录遮罩 |
| 首页仍是官方「探索未至之境 · 预览版」 | `dsh-client-ui-conversation` 写死标题与徽标，`ui-brand-official` 又占了槽 | 往 `conversation.hero.brand.mark` 槽注册 `HeroWordmark`，CSS 隐藏官方标题与徽标 |
| 侧栏出现两个「个人」 | 同一台电脑多人登录过，各自的个人工作区都留在列表 | `ensureWorkspaces` 收起非当前登录者的 `_office/*` 工作区（目录保留） |
| 设置 → 订阅 空白 | `useMemo` 写在条件 `return` 之后，hooks 顺序错 | hooks 提到函数顶部 |
| 人员表格溢出 | 长内容 + 固定宽度按钮 | `dk-table-wrap` 横向滚动、`nowrap`、加宽设置弹窗 |
| 浏览器自动化往 ProseMirror 输入得到 `undefined` | `browser_fill` 不适合 contenteditable | CDP `Runtime.evaluate` 走 `execCommand('insertText')` |
| 截图尺寸不听 `setDeviceMetricsOverride` | 默认截可视区 | `Page.captureScreenshot` 带 `clip` |
