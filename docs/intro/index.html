01 / platform

交付平台

公司网关是唯一真相源。账号、模型通道、周额度、任务卡和公司盘都在服务端；客户端只有登录会话令牌和网关令牌，上游密钥永不下发。

网关

Node 服务，默认 :8790。Windows 服务或树莓派 Docker。管理页走首次引导：公司名、管理员、通道接入。

任务四格

进行中 → 待审 → 待终审 → 通过 / 驳回。提交必须挂交付物，落在公司盘 projects/inbox/<任务ID>/。

四层知识

岗位手册 · 共享经验 · 个人记忆 · 检索层 company_knowledge。只回答谁 / 何时 / 在哪，不拷贝别人的会话。

额度

按人按周记账。通道可挂多账号轮换。Google 个人订阅走 Antigravity，不走已停用的 Gemini CLI。

02 / harness client

Harness 客户端

Electron 桌面与浏览器同一套外壳。本机跑 Agent（读文件、跑命令、写交付物），模型请求全部经网关。内核 DeepSeek Harness，由仓库锁定并打公司补丁。

会话

个人 / 团队工作区，模型按厂商分组，@ 引用本机文件，流式执行。Mixed：规划 / 实施 / 审核三角色。

公司盘镜像

共享经验、个人记忆、相关任务收件箱同步到本机。记忆可回推；交付物必须挂到任务卡。

安装

Windows NSIS 安装包；macOS 解压 .app。局域网 UDP 发现网关，与插件、pi 包同一协议。

下载 Setup.exe · 源码 npm run dist:client

03 / pi package

pi 包 · valimart pi desk

不装桌面客户端时，把同一套公司网关装进 pi CLI。TUI 花标、登录、模型目录、知识检索、公司盘同步、任务卡都在。

安装

扩展以完整系统权限运行。本机一条命令即可。

pi install npm:pi-valimart-desk

npmjs.com/package/pi-valimart-desk

登录与模型

/desk-login 先扫局域网。/model 选 valimart/<目录模型>。Shift+Tab 循环思考档位。

盘与任务

镜像 ~/.pi/agent/valimart-drive/。/desk-tasks 查看，/desk-task-new 交互建卡（指派人列表）。

04 / vscode

VS Code 插件

在编辑器里登录公司网关、侧边栏对话、Agent 改当前工作区。模型、额度、公司盘、任务卡仍然只走网关，不内嵌 DSH、不存上游密钥。

工作台

活动栏 Chat；可弹出到编辑器区。流式 Markdown、思考折叠、停止生成、改动卡片打开原生 diff。

发现网关

与桌面 / pi 同一套：本机 health → UDP 18790 → 私网 /24 扫描。选中地址记在本机。

任务卡

列表 / 新建、四格验收、交付物、会话绑定、提交与审核。当前文件与选区作为上下文发给 Agent。

工程

源码在本仓库 packages/vscode。main 推送后 GitHub Actions 自动打 vsix 挂到 Releases。

npm run dist:vscode
