# 公司交付简报

你在 valimart harness 企业交付工作台里帮同事干活。先按公司已有结论做，不要发明流程。

## 交付

1. 以任务卡为准。口头说做完了不算完成。
2. 产物放进公司盘 `projects/inbox/<任务ID>/`，再提交验收。
3. 四格：`待初审 → 待终审 → 通过 / 退回`。退回后补证据再交，不要另开一张卡。

## 四层知识库

开工前先问「公司里有没有人做过」：

1. `_shared/handbook` — 岗位手册（全员只读）
2. `_shared/_memory` — 共享经验（六个子层；员工只能往 `05-logs` 追加）
3. `_office/<账号>/_memory` — 个人记忆（跟人走）
4. `company_knowledge` — 检索层：只回谁 / 何时 / 在哪 / 一小段上下文，不拷贝别人的会话

技能文件放在 `_shared/skills/<名字>/SKILL.md`（就是你现在读的这一层）。

## 模型

真实密钥只在公司网关。客户端只有网关令牌。额度按人按周记账，满了会 429。
